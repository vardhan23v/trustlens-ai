# TrustLens AI — API reference

Base path: `/api`. Request and response bodies are JSON unless stated otherwise. Interactive docs generated by
FastAPI are served at `/docs` and `/openapi.json`.

## Conventions

- **No authentication, no rate limiting.** Put the service behind your own gateway if you need either.
- **Errors** use FastAPI's default body: `{"detail": "message"}`. Validation errors (`422`) return `detail` as a
  list of `{loc, msg, type}` objects.
- **Headers on every response:** `X-Request-ID` (your incoming `X-Request-ID` echoed back, or a new UUID) and
  `X-Response-Time` (for example `12.34ms`).
- **CORS:** `http://localhost:5173`, plus `https://$RAILWAY_PUBLIC_DOMAIN` when that variable is set. Methods `GET`
  and `POST`.
- **A Gemini failure is not an error status.** The analysis returns `200` with the deterministic and model evidence
  and `gemini_error` set.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/analyze` | Run an analysis |
| `GET` | `/api/reports/{report_id}` | Reopen a stored report |
| `GET` | `/api/demos` | List bundled demos |
| `GET` | `/api/demos/{demo_id}/image` | Demo image (JPEG) |
| `POST` | `/api/analyze/demo/{demo_id}` | Run a demo |
| `POST` | `/api/report/pdf` | Build a PDF from a report |
| `GET` | `/api/models` | Installed model slots |
| `GET` | `/api/models/selftest` | Load and run every model |
| `GET` | `/api/health` | Configuration status |

## POST /api/analyze

`multipart/form-data`

| Field | Type | Required | Notes |
|---|---|---|---|
| `mode` | `news_claim` \| `ai_generated` | yes | |
| `file` | file | one of `file` / `text` | Image, video or audio |
| `text` | string | one of `file` / `text` | Up to 8,000 characters. Ignored when a file is sent |

Accepted files, detected from the file's own bytes (the name and browser-supplied type are not trusted):

| Kind | Formats | Limit |
|---|---|---|
| Image | JPEG, PNG, WebP | `MAX_UPLOAD_MB` (default 10 MB) |
| Video | MP4, MOV, WebM | 18 MB |
| Audio | MP3, WAV, M4A, OGG | 18 MB |

```bash
curl -F mode=news_claim   -F file=@screenshot.jpg  https://<host>/api/analyze
curl -F mode=ai_generated -F file=@clip.mp4        https://<host>/api/analyze
curl -F mode=news_claim   -F "text=UNESCO declared ..." https://<host>/api/analyze
```

**Status codes**

| Code | When |
|---|---|
| `200` | Analysis returned, including degraded results (`gemini_error` set) and timeouts |
| `413` | File over its limit, or text over 8,000 characters |
| `415` | File is not a supported image, video or audio format |
| `422` | Neither a file nor text was sent, or `mode` is missing or invalid |

**Time limits** (after which the deterministic checks alone are returned): 60 s for AI-Generated images and text,
120 s for News / Claim images and text, 180 s for AI-Generated video and audio, 240 s for News / Claim video and audio.

**Repeatability:** an identical input in the same mode returns the same report, including the same `report_id`, from
a 30-minute in-memory cache and, when a database is configured, from storage. Degraded reports are not cached.

**Response:** a [`TrustReport`](#trustreport).

## GET /api/reports/{report_id}

Returns the stored `TrustReport`. Ids look like `TL-4F2A9C1B03DE` and are matched case-insensitively.

| Code | When |
|---|---|
| `200` | Found |
| `404` | No database is configured (`"Stored reports are not available on this deployment."`), or no report has that id |

There is no endpoint that lists reports. Ids are not authenticated: anyone who has one can read that report.

## GET /api/demos

Returns an array:

```json
[
  {"id": "genuine_notice", "label": "Genuine notice", "input_type": "image", "mode": "ai_generated",
   "text": null, "image_url": "/api/demos/genuine_notice/image", "cached": true}
]
```

Bundled demos: `genuine_notice` and `edited_notice` (AI-Generated), `viral_post` (News / Claim). `cached` is true
when recorded Gemini output exists for the demo.

## POST /api/analyze/demo/{demo_id}

No body. Runs the demo image through the pipeline. Forensics, the pretrained models and the assessment run live;
Gemini's output comes from a recorded fixture, and the report has `analysis_mode: "demo_cached"`. `404` for an
unknown demo.

## POST /api/report/pdf

```json
{"report": { ...a TrustReport exactly as returned by /api/analyze... }}
```

Returns `application/pdf` with `Content-Disposition: attachment; filename="TrustLens_Report_YYYYMMDD_HHMMSS.pdf"`
and the headers `X-TrustLens-Report-Id` and `X-TrustLens-Report-Writer` (`direct` or `openrouter`).

Nothing is re-analysed. The server re-derives the score and risk level from the posted signals and refuses a report
that does not add up.

| Code | When |
|---|---|
| `200` | PDF returned |
| `422` | Body is not a valid report, or its score / risk level do not follow from its signals |
| `503` | PDF generation failed |

## GET /api/models

Lists every model slot without loading anything:

```json
[{"slot": "image_synthetic", "task": "AI-generated image detector", "model": "Community Forensics ViT (ONNX)",
  "available": true, "reason": "", "limitations": ["..."]}]
```

`available` means the runtime and weights are present. It does not prove the model fits in memory; use the self-test
for that.

## GET /api/models/selftest

Loads each model and runs it on bundled inputs (a demo image, a short text-to-speech clip, one claim with three
headlines). The result is cached for the life of the process; `?fresh=true` re-runs it.

```json
{
  "seconds": 4.5,
  "memory": {"limit_mb": 1000, "used_mb": 676, "free_mb": 324},
  "threads": 2,
  "models": {"image_synthetic": {"model": "...", "status": "RAN", "detail": "Score 0.00 that the image is AI-generated (low) (0.4 s)"}},
  "outputs": {"image_p_generated": 0.0, "ocr_text": "...", "speech_p_synthetic": null, "transcript": "...",
              "headline_similarity": [0.78, 0.70, 0.08], "headline_nli": [{"label": "contradiction", "contradiction": 0.46}]},
  "working": ["asr", "embedding", "image_synthetic", "nli", "ocr"],
  "not_working": ["audio_spoof"]
}
```

`memory` is empty when the process has no container memory limit.

## GET /api/health

```json
{"status": "ok", "gemini_model": "gemini-3.6-flash", "gemini_configured": true, "factcheck_configured": false,
 "crewai_version": "1.15.23", "database": "connected", "ffmpeg": true,
 "modes": ["news_claim", "ai_generated"], "pdf_writer": "openrouter"}
```

`status` is always `"ok"` when the process is up. `gemini_configured` only says a key is set; Gemini is not contacted.
`database` is `not_configured`, `connected` or `unreachable`. `pdf_writer` is `openrouter` when both OpenRouter
variables are set, otherwise `direct`.

## TrustReport

Top-level fields. Lists are empty and objects are null when they do not apply.

| Field | Type | Meaning |
|---|---|---|
| `mode` | `news_claim` \| `ai_generated` | Mode that was requested |
| `media_type` | `image` \| `video` \| `audio` \| `text` | Kind of input |
| `report_id` | string | Id for `GET /api/reports/{id}` |
| `analysis_mode` | `live` \| `demo_cached` | |
| `overall_assessment` | Assessment | The headline answer |
| `assessment_axes` | AxisAssessment[] | One per question (claim, media authenticity, context, …) |
| `claims` | ClaimStatus[] | Atomic claims and their status (News / Claim) |
| `evidence` | Evidence[] | External sources (News / Claim) |
| `timeline` | TimelineEvent[] | Sources ordered by publication date |
| `signals` | Signal[] | Findings that feed the score |
| `evidence_signals` | EvidenceSignal[] | Every finding, source and model result in one schema |
| `stages` | Stage[] | Pipeline stages as they ran |
| `specialist_models` | SpecialistModel[] | What each pretrained model did |
| `media_metadata` | object | Container facts from ffmpeg (video / audio) |
| `change_factors` | string[] | What would change the assessment |
| `trust_score` | integer 0–100 | Risk indicator |
| `risk_level` | `LOW` \| `MEDIUM` \| `HIGH` | Band of `trust_score` |
| `score_breakdown` | CategoryBreakdown[] | Deductions per category: `raw`, `cap`, `applied` |
| `score_scope` | string | What the score measures in this mode |
| `verdict` | `VERIFIED_BY_SOURCE` \| `DEBUNKED_BY_SOURCE` \| `UNVERIFIED` \| null | Source verdict (News / Claim) |
| `confidence` | number \| null | Verdict confidence, 0–1 |
| `extracted` | object | Extracted text, claim, and fields read from the input |
| `recommendation` | string | |
| `what_to_verify`, `inconsistencies`, `notes`, `caveats` | string[] | |
| `ela` | object | Error-level analysis: `status`, `heatmap_b64`, `region`, `width`, `height` |
| `gemini_error` | string \| null | Set when Gemini was unavailable or the request timed out |
| `agents_used` | string[] | |
| `disclaimer` | string | |

Legacy fields kept for older clients: `input_type`, `analysis_intent`, `media_assessment`, `artifact_assessment`,
`confidence_boosters`, `classification`, `article`, `inputs_provided`.

### Assessment / AxisAssessment

| Field | Values |
|---|---|
| `heading` | Axis name (AxisAssessment only), e.g. `Claim assessment`, `Media authenticity`, `Context consistency`, `Visual authenticity`, `Audio authenticity`, `Audio-visual consistency`, `Synthetic / manipulation assessment`, `AI-authorship assessment` |
| `state` | `SUPPORTED`, `CONTRADICTED`, `MISLEADING_CONTEXT`, `UNVERIFIED`, `INCONCLUSIVE`, `EVIDENCE_UNAVAILABLE`, `NOT_ASSESSED`, `LIKELY_AUTHENTIC`, `LIKELY_SYNTHETIC`, `MANIPULATED`, `LIKELY_FABRICATED` |
| `label`, `summary` | Human-readable |
| `confidence` | `low`, `medium`, `high` or empty |
| `basis` | What the confidence rests on |

### Signal

`key`, `title`, `severity` (`high` \| `medium` \| `low`), `category` (`image_forensics`, `visual_analysis`,
`url_domain`, `message_content`, `claim_evidence`), `sources` (any of `RULE`, `GEMINI`, `MODEL`), `explanation`,
`evidence`, `uncertainty`, `penalty`.

### Evidence

`source`, `url`, `title`, `quote`, `published` (`YYYY-MM-DD` or empty), `source_site`, `source_type` (`official`,
`wire`, `established`, `factcheck`, `other`), `rating`, `stance` (`supports`, `refutes`, `mixed`), `claim_index`,
and the model second opinion: `relevance` (cosine similarity or null), `nli_label` (`entailment`, `contradiction`,
`neutral` or empty), `nli_score`, `stance_note` (why a source was set aside).

### EvidenceSignal

`signal_id`, `category`, `modality`, `source_type` (`RULE`, `MODEL`, `GEMINI`, `EXTERNAL_SOURCE`), `model`,
`finding`, `direction` (`SUPPORTS`, `CONTRADICTS`, `NEUTRAL`, `UNKNOWN` — relative to the claim being true or the
media being authentic), `confidence`, `reliability`, `relevance`, `dimension` (`claim`, `media_authenticity`,
`context`, `content_risk`), `evidence`, `source_reference`, `limitations`.

### Stage

`name`, `status` (`done`, `skipped`, `failed`, `unavailable`), `detail`.

### SpecialistModel

`slot`, `task`, `candidate` (the installed model), `status`, `detail`, `limitations`.

| `status` | Meaning |
|---|---|
| `RAN` | Inference succeeded; `detail` holds the real output and timing |
| `NOT_APPLICABLE` | The input has nothing for this model (for example no audio track) |
| `NOT_RUN` | Installed but not needed for this input |
| `FAILED` | The model raised an error on this input |
| `MODEL_UNAVAILABLE` | Not installed, weights missing, switched off, or not enough memory; `detail` says which |

### ClaimStatus

`text`, `dimension`, `status` (`SUPPORTED`, `CONTRADICTED`, `MIXED`, `UNVERIFIED`), `supporting`, `contradicting`
(counts of independent listed sources).

### TimelineEvent

`date` (`YYYY-MM-DD` or `UNKNOWN`), `source`, `title`, `stance`, `url`.
